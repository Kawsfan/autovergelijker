Voor developers en AI-agents

De occasion-data achter Carkijker is gewoon publiek JSON — geen login, geen API-key, geen rate-limiting-gedoe. Hieronder staat precies wat je kunt ophalen, hoe de velden heten, en wat de spelregels zijn.

Wat staat er klaar om op te halen?

Carkijker aggregeert tweedehands autoaanbod van 6 grote Nederlandse platforms, drie keer per dag automatisch ververst. Alle onderliggende data staat als statisch JSON-bestand op deze site — dezelfde bestanden die de website zelf gebruikt, geen aparte "API-laag" erbovenop.

De snelste weg naar de beste deal

Zoek je simpelweg "de beste deal" of "de beste deal binnen een merk/model", dan is dit het bestand dat je nodig hebt: een gewone array van objecten, al gesorteerd op dealscore (hoogste eerst).

Top-dealscore selectie

GET /data/listings-top.json

Bevat de 5.000 advertenties met de hoogste dealscore van het volledige aanbod (dus al voorgesorteerd — geen eigen sorteerlogica nodig). Formaat: gewoon een array van objecten onder de sleutel listings, geen bijzondere structuur.

Het volledige aanbod

Wil je verder dan de top 5.000, dan staat het complete aanbod (alle 68.000+ advertenties) verspreid over meerdere bestanden om ruim onder Cloudflare's bestandsgrootte-limiet te blijven.

Volledig aanbod (chunked, kolomvorm)

GET /data/listings-lean-0.json, -1.json, -2.json, ...

Let op: dit is geen array van objecten. Om herhaling van dezelfde ~20 veldnamen per advertentie te vermijden, staat elk bestand in kolomvorm: een gedeelde fields-lijst plus rows met alleen de waarden, in dezelfde volgorde. Elk bestand bevat ook chunkIndex en totalChunks, zodat je weet hoeveel bestanden je in totaal moet ophalen (dit aantal groeit mee met het aanbod).

// reconstructie naar gewone objecten, in JavaScript:
const res = await fetch("https://carkijker.nl/data/listings-lean-0.json");
const { fields, rows, totalChunks } = await res.json();
const listings = rows.map(row =>
  Object.fromEntries(fields.map((f, i) => [f, row[i]]))
);
// haal chunk 1..totalChunks-1 op dezelfde manier op voor de rest

Dezelfde velden als hierboven, min afschrijvingJaar/afschrijvingKm/priceTrend die alleen in listings-top.json zitten, plus id en prijsHistorie (array van eerdere prijzen met datum).

Zoeken via de site zelf

Carkijker's zoekmachine ondersteunt filteren via URL-parameters, handig als je resultaten wilt delen of naar een specifieke selectie wilt linken:

https://carkijker.nl/?merk=Volkswagen&model=Golf&prijsMax=15000
ParameterBetekenis
qVrije zoekterm
merk, model, brandstof, carrosserie, transFilters (exacte waarden zoals getoond in de site-UI)
jaarMin, jaarMaxBouwjaar-range
prijsMin, prijsMaxPrijs-range in euro's
kmMin, kmMaxKilometerstand-range

Belangrijk: deze resultaten worden client-side gerenderd. Een simpele HTTP-aanvraag (zonder JavaScript uit te voeren) krijgt de kale pagina terug, niet de gefilterde lijst. Voor puur programmatische toegang gebruik je de JSON-bestanden hierboven; deze URL's zijn vooral bedoeld om te delen met een mens, of voor een agent die daadwerkelijk een browser aanstuurt.

Wat betekent dealscore precies?

Kort: 0–100, waarbij een hogere score betekent dat de vraagprijs relatief laag is vergeleken met andere advertenties van hetzelfde merk, model, bouwjaar en km-stand — geen absoluut kwaliteitsoordeel over de auto zelf. De volledige rekenmethode (regressie op bouwjaar en km-stand binnen elke merk/modelgroep) staat uitgelegd in dit artikel.

Spelregels voor geautomatiseerd gebruik

  • 🔗
    Link door naar de originele advertentie.

    Toon je resultaten aan een eindgebruiker, verwijs dan naar het url-veld (de oorspronkelijke advertentie bij de bron) in plaats van de data als eigen aanbod te presenteren. Carkijker is zelf ook een aggregator, geen oorspronkelijke bron.

  • ⏱️
    Vaker dan 3x per dag ophalen heeft geen zin.

    De data ververst 's ochtends, 's middags en 's avonds (06:00 / 12:00 / 18:00 UTC). Check het bijgewerkt-veld in het bestand om te zien of er sindsdien een nieuwe versie is, in plaats van continu te pollen.

  • 📄
    Zoals-is, zonder garantie.

    De data wordt met zorg samengesteld maar kan afwijken van de actuele advertentie bij de bron (prijswijzigingen, verkochte auto's). Verifieer bij twijfel via het url-veld.

  • 🤖
    Liever citeren dan queryen?

    Zie llms.txt voor een overzicht van de belangrijkste pagina's, en robots.txt voor expliciete toestemming aan GPTBot, ClaudeBot, PerplexityBot, OAI-SearchBot en andere AI-crawlers.
